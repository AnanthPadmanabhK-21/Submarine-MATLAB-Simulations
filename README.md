# Submarine-MATLAB-Simulations
This repository contains the implementation and simulation work carried out as part of a mini-project on an Autonomous Underwater Submarine System. The project focuses on three major aspects of underwater robotics: image processing for surface condition detection, navigation and stabilization using control systems, and communication simulation between control station and vehicle.

The first module implements an image processing pipeline developed in MATLAB for detecting rust or surface damage from captured images. The algorithm reads an input image, converts it to grayscale, removes noise using median filtering, and applies Canny edge detection to identify cracks and surface boundaries. A color segmentation technique is then used to isolate reddish-brown regions representing rust. The script calculates the percentage of rust coverage and overlays the detected regions on the original image to visualize deterioration. This module demonstrates how computer vision can be applied for inspection of underwater structures and vehicle surfaces.

The second module presents a PID-based yaw stabilization simulation of a submarine. A mathematical model is used to simulate external disturbances such as underwater currents. A Proportional-Integral-Derivative controller is implemented to maintain the desired yaw angle. The simulation shows how tuning the controller gains affects system stability, overshoot, and steady-state error. Graphical results are generated to visualize the yaw response and control signal over time, demonstrating the effectiveness of feedback control in underwater navigation.

The third module simulates command communication between a control station and a submarine using a UDP-style message exchange approach in MATLAB. The program allows the user to send navigation commands such as forward, reverse, left, right, and stop. The receiver interprets the command and generates corresponding motor responses. This module demonstrates the basic concept of real-time command transmission and interpretation in an underwater robotic system.

Overall, the repository represents the foundational simulation and algorithm development stage of an autonomous submarine project. The work demonstrates the integration of image processing, control systems, and communication concepts using MATLAB and Python to build a preliminary software framework for underwater robotic applications.
